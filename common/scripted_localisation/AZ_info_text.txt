# Azarya: logica de texto do "Arquivo de Azarya" - rotulos das 4 abas e o
# texto do painel simples (abas 1 "Visao Geral" e 2 "Sua Nacao").
#
# NOTA TECNICA: um "defined_text" com o mesmo nome nao pode ser dividido em
# vários arquivos (a definicao mais recente carregada substitui a anterior
# inteira, nao mescla - mesmo comportamento de spriteType/etc). Por isso
# GetInfoPanelText fica inteiro aqui, inclusive a ramificacao por pais da
# aba "Sua Nacao"; quem foi dividido em arquivos separados foi o TEXTO em si
# (localisation/AZ_country_briefings_l_english.yml), nao a logica.
#
# Pra adicionar o briefing de uma nova nacao: acrescentar um bloco
# "text = { trigger = { check_variable = { az_info_tab_page = 2 } check_variable = { az_info_country_tag = TAG } } localization_key = "AZ_COUNTRY_BRIEFING_TAG" }"
# aqui embaixo (antes do fallback generico) e escrever o texto correspondente
# em localisation/AZ_country_briefings_l_english.yml.

	name = GetInfoTab1
	text = {
		localization_key = "AZ_INFO_TAB_OVERVIEW"
	}
}
