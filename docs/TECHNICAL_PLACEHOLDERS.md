# Technical placeholders

The following temporary assets are valid game files intended to prevent broken
references while bespoke art is pending. They must be replaced before release.

- `gfx/texticons/country_view_map.png` and the `CZL`, `SIT`, `NIC`, `SRV`,
  `SLU`, and `LUQ` variants reuse the existing THK country-view map.
- Flags for `INV`, `KES`, `DKM`, `EYD`, `KRT`, `ORV`, and `LIA` reuse the CZL
  flag in normal, medium, and small sizes.
- `gfx/loadingscreens/load_mtg_2.dds` reuses the validated `load_1.dds`
  image until a dedicated Man the Guns loading screen is available.
- Karyō, Liangor, and Orvena use the existing generic leader portrait asset.
- Aelosia uses `Portrait_PLACEHOLDER_large.dds` and its paired
  `Portrait_PLACEHOLDER_small.dds`, avoiding the malformed legacy
  `leader_unknown.dds` filename.
- `AZ_focus_icon_fallbacks.gfx` supplies generic Lesc focus and paired
  hover/shine sprites using already-loaded interface artwork.
